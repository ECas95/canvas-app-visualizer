# Canvas Source Format Support

## Supported

### Active `.pa.yaml` source

The parser targets the active Canvas source-code format generated by Power Apps Studio.

Supported top-level concepts:

- `App`
- `Screens`
- `ComponentDefinitions`
- `DataSources`

Controls are normalized from the ordered `Children` sequence.

Control identifiers with versions such as `Label@1.2.3` are split into control type and version.

### Modern `.msapp`

A modern `.msapp` can be opened when it contains active `.pa.yaml` source under `Src/`.

The application extracts only those source files.

## Intentionally ignored

Package JSON outside `Src/` is not treated as source code.

## Not supported as active format

Retired `.fx.yaml` source is not treated as the current Canvas source format.

Older `.msapp` packages without active `Src/*.pa.yaml` cannot be visualized by the MVP. The user is told to resave the app through current Power Apps tooling first.

## Important limitation

The Canvas YAML schema is actively developed and may be incomplete. Compatibility must therefore be versioned and tested rather than assumed.
